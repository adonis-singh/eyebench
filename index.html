Methodology

Every question has a single number as its answer and is marked right or wrong. A question with no parsed answer, including an invalid output or a failed request, counts as wrong. Each model is listed at its highest measured reasoning effort. Effort names are set by each provider and don't compare across vendors. The whiskers show ±1 standard error. Costs are the tokens each run used at the model's API prices. Caching never comes into play, since each question is a single request.
